# AWS Serverless Task Tracker

## Overview

A serverless task management application built using AWS Lambda, API Gateway, DynamoDB, Cognito and S3.

## AWS Services Used

- AWS Lambda
- Amazon API Gateway
- Amazon DynamoDB
- Amazon S3
- Amazon Cognito
- AWS IAM
- Amazon CloudWatch

## Features

- User Authentication
- Create Tasks
- View Tasks
- Update Tasks
- Delete Tasks

## Technology Stack

- AWS
- Node.js
- HTML
- CSS
- JavaScript
