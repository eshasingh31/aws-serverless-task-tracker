# AWS Serverless Task Tracker

## Overview

AWS Serverless Task Tracker is a cloud-native task management application built using AWS serverless services. The application enables users to securely create, view, update, and delete tasks through a web-based interface while leveraging scalable and cost-effective AWS infrastructure.

## AWS Services Used

* AWS Lambda
* Amazon API Gateway
* Amazon DynamoDB
* Amazon S3
* Amazon Cognito
* AWS IAM
* Amazon CloudWatch

## Features

* User Authentication using Amazon Cognito
* Create Tasks
* View Tasks
* Update Tasks
* Delete Tasks
* REST API Integration
* Serverless Architecture
* Secure Access Control with IAM
